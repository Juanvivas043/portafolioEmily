# Requisitos

- Formulario reusable, y seccion de contacto que sea rehusable que use este
  formulario, de forma que el formulario se puede implementar el formulario solo
  o la seccion si lo quieres asi
- Diseño responsive, verifica que sea esteticamente agradable en movil, tablet y
  escritorio.
- Header, footer y el header mobile que sea un menu de hamburguesa que despliege
  un sidebar lateral con overlay y que entre con animacion de entrada y salga
  con una de salida.
- El sitio web debe estar priorizando el static side rendering para la carga de
  la pagina.
- Las imagenes o videos a usar deben estar en formato webm o webp, si no estas
  las transformas tu, y siempre verifica que se optimicen adicional las imagenes
  y videos, busca reducir el peso y la mejor calidad posible
- Implementa estrategias para la carga de imagenes con next que ya trae algunas
  comodidades para esto
- El sitio me gustaria que tambien se enfocara en las animaciones parallax y que
  se sienta que con el scroll la pagina va armandose o apareciendo y
  desaparecinedo el contenido de forma fluida
- para el formulario usaremos nodemailer, puedes desarcarglo y se usara la
  contrase;a de aplicaciones de google, coloca uno de prueba que no funcionara.
- recuerda que la web esta orientada a una creadora de contenido del area de
  marketing, debe ser un dise;o creativo y que no sea traidicional y que se vea
  generico y generado por IA, manteniendo los requisitos que te plasmo o el
  contrato plasmado
- Busca tambien el bajo acoplamiento y la alta cohesion al crear el sitio web
- para los iconos si hace falta puedes usar lucide react
- usa los recursos de next js 16 para mejorar el rendimiento de la aplicacion
